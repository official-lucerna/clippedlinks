# ⚡ Features
- Save your favorite links with end-to-end encryption for complete privacy.
- Choose from 3+ beautiful layouts to display your links your way.
- Share your workspaces and bookmarks confidently without compromise.

# ⚙️ Installations
## Github
```
git clone https://github.com/official-lucerna/clippedlinks
```

## NpmJS
```
npm install
```

## PNPM
```
pnpm install
```

# 🛠️ Setup
In order to run ClippedLinks, it is first necessary to configure it by making adjustments to the `example.config.toml` (remove the `example.` part in the name afterwards) file. All of the necessary descriptions for each variable are already included.

# 📦 Deployment
To deploy ClippedLinks, first create a [Vercel](https://vercel.com/) account. Then, install Vercel with the command `npm i vercel -g` and run the command `vercel --prod`. It's done! You can now use it on your websites.

# 🚀 Usage
```
node index.js
```
